# projetos_cdt

Tema: Sorverteria

Integrantes: Gustavo Rodrigues, Rhuan Carlos e Wilson Silva

Nosso projeto foi realizado em grupo, utilizando HTML como base, CSS para estilização e JS para impletação de funções. Trata-se de um sistema de sorveteria que permite ao usuário acessar cardápio, barra de pesquisa, adicionar ao carrinho, realizar pedidos, se cadastrar e pedir ajuda. Pode ser  acessado em página da web através de link ou arquivo salvo.
